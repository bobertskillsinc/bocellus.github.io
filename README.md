# bocellus — Professional Tourism Website V1

Static multi-page tourism website prepared for GitHub Pages.

## Pages
- Home
- Destinations
- Experiences
- Tours
- Packages
- Plan a Journey
- About
- FAQ
- Contact
- 404

## Important
All tour/package prices, destinations, availability, forms and service claims are demo content until officially verified.
Forms are static and need a backend or email integration to submit data.

## GitHub Pages
Upload the unpacked files to the root of `bocellus.github.io`.
Then go to Settings → Pages → Deploy from branch → `main` → `/(root)` → Save.
